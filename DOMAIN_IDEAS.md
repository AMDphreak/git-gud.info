# Domain name ideas

Ideas for a custom domain for this Git docs site. Primary name in use: **git-gud.info** (configured as `site` in Astro; DNS may still park elsewhere until pointed at GitHub Pages).

Projected GitHub Pages URL: https://amdphreak.github.io/git-gud.info/

Other ideas (if renaming later):

- **sensible-git.dev** — "sensible" + Git, .dev for dev tools
- **git-ref.dev** — short for "Git reference"
- **gitsense.io** — Git + sense (sensible)
- **gitcheat.dev** — cheat sheet focus
- **dailygit.com** / **dailygit.dev** — "daily" commands first
- **gitfirst.dev** — common commands first
- **gitflow.ref** — workflow + reference (if .ref is available)
- **git-one-pager.dev** — one-place reference
- **nogitmaze.com** — "no maze, no jargon" (from tagline)
- **gitplain.dev** — plain, no-nonsense docs

Point the chosen domain at the GitHub Pages URL (or configure Pages custom domain in repo settings). Do not change DNS for git-gud.info until ready to cut over from the current parking target.
