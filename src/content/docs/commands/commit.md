---
title: git commit
description: Saves a snapshot with a message.
---

```bash
git commit -m "Your message here"
```

**What it does:**

- Saves a snapshot of everything you staged with `git add`.
- The `-m` part is the message. You must give a message on the command line. If you don’t, Git opens an editor.

**Good messages:** Short. Present tense. Examples: “Add login form”, “Fix typo in README”.
