<summary><strong>Getting started</strong> — Install Git and make your first commit</summary>

1. **Install:** [git-scm.com](https://git-scm.com) or `winget install Git.Git` (Windows), `xcode-select --install` (macOS).
2. **Configure once:** `git config --global user.name "Your Name"` and `git config --global user.email "you@example.com"`
3. **Get a repo:** `git clone <url>` or `git init`
4. **First commit:** `git add .` → `git commit -m "First commit"` → `git push -u origin main` (if you use a remote)

Full steps: [Getting started](/getting-started/)
